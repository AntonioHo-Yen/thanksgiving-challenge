# Thanksgiving Challenge Landing Page

A responsive, holiday-themed promotional landing page built for a holiday sales and community outreach campaign. Developed as part of the CodingPhase coding challenge.

## Overview
This project was built to deliver an engaging user experience for a Thanksgiving seasonal campaign. It features a festive layout designed to drive user engagement, complete with promotional highlights, a retail store locator, and community charity donation components.

## Built With
* HTML5: Semantic document structure and accessible markup.
* CSS3: Modern styling utilizing Flexbox/Grid for responsive layouts.
* Git & GitHub: Version-controlled with cryptographically signed SSH commits for strict repository integrity.

## Key Features
* Responsive Design: Optimized for mobile, tablet, and desktop viewports.
* Interactive Components: Designed with clean user interaction flows for promotional features and store location lookups.
* Semantic Architecture: Clean, maintainable code structure adhering to modern front-end standards.
